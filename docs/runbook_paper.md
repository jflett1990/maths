# Paper Mode Runbook
- Set `mode: paper`.
- Ensure `mode_controls.allow_live_orders: false`.
- Run `python scripts/run_paper.py --config configs/base.yaml`.
- Inspect `state/run_report.json` and canonical streams:
  - `state/market_snapshots.jsonl`
  - `state/wallet_observations.jsonl`
  - `state/signals.jsonl`
  - `state/decisions.jsonl`
  - `state/orders.jsonl`
  - `state/fills.jsonl`
  - `state/pnl.jsonl`
  - `state/run.jsonl`
  - `state/reconciliation_anomalies.jsonl`
